# مركبات شفيق

تطبيق عربي باتجاه RTL لعرض سجلات المركبات والبحث فيها وتصفيتها حسب حالة التأمين. تظهر تفاصيل كل مركبة في نافذة حوار على الشاشات الكبيرة أو درج سفلي على الهواتف، مع إمكانية نسخ الحقول المتاحة. البيانات مضمّنة في التطبيق، ولا يتطلب التشغيل خادماً.

## المتطلبات والتشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm ci
npm run dev
```

للتحقق من الأنواع وإنشاء نسخة الإنتاج:

```bash
npm run typecheck
npm run build
npm run preview
```

## واجهة المستخدم

تستخدم الواجهة مكونات محلية على نمط shadcn/ui مبنية على Radix UI وVaul، مع Tailwind CSS. المكونات قابلة للتخصيص ضمن `src/components/ui`.

## النشر على GitHub Pages

تم ضبط مسار النشر في `vite.config.ts` على `/route-vehicles-shafeek/`. سير العمل `.github/workflows/deploy.yml` يبني التطبيق وينشره عند الدفع إلى `main`.

في إعدادات المستودع، اختر **Settings → Pages → GitHub Actions** كمصدر للنشر.

## ملاحظات البيانات

- تتضمن البيانات السجلات الأربعة عشر المقدمة.
- الحقول غير المتوفرة تظهر بشرطة ولا يمكن نسخها.
- التواريخ كما وردت في الملف المقدم وبالتقويم الهجري.
- ترتيب الأحرف الإنجليزية يتبع المثال المقدم: `أ ن ع → E N A`.
- ينبغي مطابقة الأرقام والبيانات مع مصدرها الأصلي قبل استخدامها كسجل تشغيلي موثوق.
